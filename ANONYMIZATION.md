# Anonymization record

The deliverable contains no author names, affiliations, email addresses,
account names, machine names, repository URLs, API credentials, or absolute
filesystem paths.

The cleanup also removed development-only modules, internal experiment
results, persistent caches, workload logs, and dataset-specific notes. The
remaining example text is synthetic and contains no personal data.

Before distribution, the directory was scanned for common identity, path, and
secret patterns, and the package test suite was run from the cleaned source.
